# 课程总体纲要

企业实践约60%，社会理论约40%，交叉教学；不限定总课时。以理解、应用、迁移、制度设计为能力标准。

## 1. 财富与经济基础

财富生产、价值与价格、产权、工资与议价、利润与剩余价值、分配与公平。

## 2. 企业经营与商业模式

需求与客户、商业模式、单位经济、现金流、竞争、定价、风险与增长。

## 3. 组织管理与制度设计

组织结构、委托代理、绩效、激励相容、监督、授权、治理、机制实验。

## 4. 人性与博弈论

理性与偏差、信息不对称、谈判、重复博弈、合作、集体行动。

## 5. 社会结构与政治经济学

国家与合法性、公共品、税收、公共选择、阶层、社会流动、制度约束。

## 6. 历史与制度比较

农业与工业化、企业制度演变、不同经济制度、历史比较、因果证据。

## 教材与考核标准

每课30分钟左右，明确目标、至少三个案例、数字推演、反例、企业与社会迁移、三道自测与解析；每七课综合考核。配3–5张有教学意义的图，真实资料注明来源及授权，假设明确标注。公开教材不保存个人成绩。每天集中提交一次，禁止逐文件触发部署。
