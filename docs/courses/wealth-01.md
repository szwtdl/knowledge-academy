# 第一课：财富是怎样产生的？

> 财富与经济基础 · 第 01 课 · 2026-11-25

## 学习目标

学习后，你应能区分营业收入、增加值、利润与劳动报酬，并解释劳动、资本和组织如何共同创造价值。

## 1. 从一家餐厅开始

假设一家餐厅每月营业收入50万元，外购食材及服务20万元，工资18万元，折旧2万元，其他税费及利息2万元。简化假设下，利润为8万元。

| 项目 | 金额 |
| --- | ---: |
| 营业收入 | 50万元 |
| 外购食材及服务 | 20万元 |
| 工资 | 18万元 |
| 折旧 | 2万元 |
| 其他税费及利息 | 2万元 |
| 利润 | 8万元 |

收入减去外购中间投入得到30万元增加值（假设其余项目均非中间投入）。增加值不是老板的利润，也不是员工的工资总额。

## 2. 为什么劳动者不获得全部收入？

厨师提供劳动，投资者提供设备和资金，经营者组织采购与销售，消费者决定是否购买。缺少其中某些条件，产品可能无法实现市场价值。贡献如何转化为报酬，还取决于合同、产权、议价能力和市场竞争。

现代经济学通常从生产要素、机会成本和边际贡献解释报酬；马克思主义政治经济学则着重研究劳动、生产资料所有权和剩余价值的关系。两者的概念与计量口径不同，不能简单把会计利润等同于剩余价值。

## 3. 三个对照案例

- 餐厅：如果厨师掌握稀缺技术，他可能获得更高工资，但也要考虑市场需求。
- 软件企业：一套软件可以重复销售，研发成本与每新增客户的服务成本不同，收入未必与当期工时成正比。
- 农业合作社：劳动者共同拥有部分资产，可以按章程分享经营剩余，但也共同承担经营风险。

以上均为教学假设，不代表实际企业数据。

## 4. 制度实验

餐厅把每月利润中的2万元用于员工奖金。如果奖金没有带来额外产出，利润降为6万元；如果奖金使扣除新增非奖金成本后的收益增加5万元，利润则为11万元。激励是否有效，需要用数据验证，并检查质量、安全与公平性。

![奖金制度结果对比](/images/wealth-incentive.svg)

## 5. 从企业到社会

企业通过合同组织生产，国家通过法律、公共服务与税收影响资源配置。二者都有规则与激励，但国家的公共责任、权力来源和约束不同于企业，不能直接类比。
