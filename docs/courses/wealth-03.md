# 第三课：产权——为什么所有权能够改变人的行为？

> 财富与经济基础 · 第 03 课 · 2026-11-27 · 建议学习时间 30 分钟  
> 本课企业、人物、金额与资源数量均为教学假设，四幅图为原创教学图表，不代表真实调查。法律制度因地区和资产类型而异，本课讨论经济机制，不作为具体法律意见。

前两课解释财富怎样产生、交易价格怎样形成。今天再追问一层：假如同一台设备、同一套软件、同一片土地交给不同的人管理，仅仅改变使用、收益和责任规则，为什么生产结果可能完全不同？

## 学习目标与路线（2分钟）

概念与权利束（5分钟）→ 设备投资（6分钟）→ 软件治理（6分钟）→ 共有资源与制度迁移（6分钟）→ 自测（5分钟）。

学完应能区分所有、使用、决策、收益与责任；计算不同收益规则下的投资激励；解释共有资源的过度使用；设计权利清晰、责任匹配且可监督的制度。

## 1. 产权不是一张孤立的所有权证书（5分钟）

一台机器由甲公司所有，租给乙公司使用，由乙公司的员工操作；乙公司获得加工收入，甲公司获得租金，维修费用按合同分担。谁是所有者、谁控制日常操作、谁得到收益、谁承担风险，并不是同一个问题。

经济分析常将产权理解为一组围绕资源的权利与约束。下表是分析工具，而非某一法律体系的固定权利分类。

| 分析维度 | 要问的问题 | 设备租赁示例 |
| --- | --- | --- |
| 归属 | 资产依法属于谁？ | 甲公司 |
| 使用 | 谁在何种条件下可以使用？ | 乙公司按合同使用 |
| 决策与排他 | 谁能改变用途、授权或限制他人使用？ | 依法律和合同分配 |
| 收益 | 谁获得租金、经营收入或剩余？ | 双方分别取得约定收益 |
| 转让 | 谁能出售、许可或转租？ | 受权利范围和合同限制 |
| 责任 | 谁承担维护、损害与违约成本？ | 按适用法律及合同确定 |

![一项资产的不同权利与责任](/images/property-03-bundle.svg)

在不完备合同理论中，合同不能事先穷尽未来所有情况，剩余控制权便成为重要问题：当合同没有约定某个新用途时，谁有权决定？谁可以拒绝？这样的权力可能改变事前投资的意愿。

但收益权和控制权不是无限的。劳动保护、债权人权利、环境规则、数据保护与公共利益都可能构成约束。拥有软件知识产权也不意味着拥有客户数据，更不意味着可以任意使用个人信息。

## 2. 案例一：谁愿意为设备升级投资？（6分钟）

一家加工企业的员工发现一项改进，可以让设备在未来一年增加12万元净经营收益（已扣除其他新增经营成本，但未扣除本次改造投入）。改造需要投入4万元。假设没有资金约束、不考虑时间价值和税费，双方对收益预测一致。

| 方案 | 员工承担改造成本 | 员工获得新增收益 | 员工净收益 | 企业净收益 |
| --- | ---: | ---: | ---: | ---: |
| A：员工自费、固定工资 | 4万 | 0 | −4万 | 12万 |
| B：员工自费、分享50% | 4万 | 6万 | 2万 | 6万 |
| C：企业出资、员工奖励2万 | 0 | 2万 | 2万 | 6万 |

![相同技术改进，不同收益与成本归属](/images/property-03-investment.svg)

上表假定改造已经完成。现实中 A 可能根本不发生：如果员工只按财务利益判断，自费4万元却没有额外收益，就没有投资动力。B 和 C 使员工的财务净收益为正，企业也保留收益。总净收益始终为12−4＝8万元；制度改变的是收益分配以及项目是否会被实施。

设员工自费且分成比例为 s，则员工净收益为 12s−4（单位：万元）。不亏损要求 s≥1/3，严格正收益要求 s>1/3。如果新增收益只有6万元，则不亏损比例升为2/3。实际还需为风险、时间与努力保留补偿。

**反例：** 如果员工无法融资，或者新增收益很难归因，即使给出50%分成，也未必能落实。企业出资、按经过验证的成果奖励、分期验收可能更合适。不能把所有激励问题简单变成股权问题。

经营实务应提前明确改造批准权、质量验收、收益核算口径、支付时间和失败损失归属。不能在员工投入之后随意改变分成规则，否则下一次投入意愿会降低。

## 3. 案例二：软件合伙人持股就一定能合作吗？（6分钟）

假设一家软件公司两名创始人各持股50%。甲负责技术，乙负责销售。公司章程与合同没有就预算、知识产权许可、退出和重大决策约定清晰程序。某日两人对是否投资新产品意见相反，即使双方股份平等，也可能陷入僵局。

现在假设有一个已批准的项目，可以增加30万元经营现金流，甲投入的时间机会成本折合8万元，乙投入的机会成本折合5万元。仅为解释激励，假定项目产生的现金流全额按约定分配，无税费、留存及其他成本，不把这个模型当成实际股东分红规则。

| 分配方案 | 甲净收益 | 乙净收益 | 合计净收益 |
| --- | ---: | ---: | ---: |
| 50% / 50% | 15−8＝7万 | 15−5＝10万 | 17万 |
| 20% / 80% | 6−8＝−2万 | 24−5＝19万 | 17万 |
| 40% / 60% | 12−8＝4万 | 18−5＝13万 | 17万 |

![软件合伙方案的净收益对比](/images/property-03-founders.svg)

在这个假设中，第二种方案可能使技术合伙人拒绝投入。第一、第三种方案都能使双方获得正的项目净收益，但不能仅凭这组数字认定某一比例更公平或更适合长期治理。

股份比例、日常管理权、重大事项表决和项目报酬需要分别设计。企业可以按实际情况明确预算授权、保留事项、知识产权归属与许可、分红政策、退出估值原则、僵局解决程序；同时保留对少数股东、员工和客户的必要保护。

### 从产权理论到政治经济学

现代制度经济学强调产权界定、交易成本、合同可执行性与投资激励；不完备合同理论分析控制权如何影响专用性投资。马克思主义政治经济学则关注生产资料所有制、劳动者与资本的关系，以及剩余如何被占有和分配。两者的问题意识与理论口径不同，但都提示我们：不能只看资产技术效率，还要分析谁拥有决定权、谁取得收益、谁承担代价。

## 4. 案例三：为什么共有资源可能被过度使用？（6分钟）

假设两个经营者共同使用一片可再生资源。每人可选节制开采或高强度开采。节制者当期收入6万元，高强度者当期收入9万元；若仅一人高强度开采，资源损失折算为每人2万元；若两人都高强度开采，则因超过资源承载能力，每人损失5万元。净收益如下。

| 甲的选择 / 乙的选择 | 乙节制 | 乙高强度 |
| --- | --- | --- |
| 甲节制 | 6，6 | 4，7 |
| 甲高强度 | 7，4 | 4，4 |

![共同资源开采收益矩阵](/images/property-03-commons.svg)

当乙节制时，甲从6变为7，有增加开采的动力；当乙高强度时，甲的两种选择都得4。因此高强度是甲的弱优势策略，对乙同理。双方高强度是一个纳什均衡，但双方节制的总收益12万元高于高强度组合的8万元。注意：这个模型并非严格的经典囚徒困境，因为某些选择的收益相等；不能据此断言唯一均衡。

如果建立一个可信的共同规则，高强度开采者需承担2万元额外费用，且可准确监督、无其他执行成本，则无论乙作何选择，甲节制都更有利。实际设计必须考虑监测费用、费用用途、误判、申诉、资源承载量变化和公平分配。

共有资源不等于无人管理。社区共有、合作社、配额制度、公共监管与私人产权都可能在一定条件下有效，也可能失败。奥斯特罗姆的共同资源研究提醒我们关注清晰边界、参与式规则、监督、适度制裁与冲突解决，而非只在私有化与集中管理之间二选一。

### 案例四：公共基础设施的控制权

假设城市需要一套防洪设施，建设成本由社会共同承担。如果将某些维护和运营任务委托给企业，可以利用专业化分工；但是防洪安全涉及多个居民群体，运营方可能没有充分动力考虑所有外部影响。公共部门应明确安全标准、监督方式、资金责任及事故处理。公共所有也不自动保证高效，需要预算透明、专业能力和问责。

### 企业与社会迁移

- 企业：画出自己一个 SaaS 项目的权利责任表，分别列出代码权属、客户数据使用权限、管理员操作权限、收益归属、故障责任和退出机制。不要用“公司拥有一切”替代具体规则。
- 社会：对同一项公共资源比较私人经营、社区共管与公共管理。统一比较资源可持续性、服务可及性、执行成本、权利保障和申诉机制，避免只比较短期收入。
- 实验：先选择一个可逆、小规模的规则变更，记录投资意愿、实际投入、质量、净收益及纠纷数量。明确对照条件，不因一次结果就认定产权制度的普遍优劣。

<summary>参考解析</summary>

服务器资产归属与云服务使用权限由服务关系确定；软件的知识产权与许可需要依据权属和合同判断；发票资料的数据处理受授权、用途和适用法律约束；管理员权限只是执行具体操作的技术授权，不产生任意处分资产或数据的权利。制度应明确权限最小化、日志审计、数据退出和责任归属。

**第2题｜计算：** 某项改造预计增加10万元净经营收益（尚未扣除改造成本），员工承担3万元投入。公司给员工25%的新增收益，员工净收益是多少？至少要多少分成比例才能不亏损？若改成公司承担全部成本、员工获得2万元奖励，双方净收益分别是多少？

<details>
<summary>参考解析</summary>

员工净收益为10×25%−3＝−0.5万元。不亏损比例为3÷10＝30%，若要求严格正收益则需超过30%。公司出资并支付奖励时，员工获2万元（假设无其他个人成本），公司获10−3−2＝5万元，合计7万元。实际方案还需考虑努力、风险、资金与归因。

</details>

**第3题｜制度设计：** 某连锁企业的多个门店共用广告预算。门店可以申请更多资源，但其申请会减少其他门店可用额度。设计一套预算使用规则，避免过度申请，并说明为什么不能只按销售额分配。

<details>
<summary>参考解析</summary>

可设置基础额度、增量申请条件和统一项目收益口径，保留小规模试验预算，记录获客成本、净贡献和实际消耗；对异常或重复申请实施可申诉的审核，周期性调整配额。单按销售额可能偏向成熟门店、忽视利润及新店成长，也可能诱发冲量。应同时评价投入产出、长期价值、机会公平和监督成本。

</details>

## 本课结论

产权制度改变的不是资产本身，而是人们能够做什么、能够得到什么，以及必须为哪些后果负责。清晰的权利有助于降低不确定性，但制度能否有效还依赖执行能力、交易成本、权力约束与利益分配。

延伸阅读：Ronald Coase, *The Problem of Social Cost*（1960）；Oliver Hart, *Firms, Contracts, and Financial Structure*（1995）；Elinor Ostrom, *Governing the Commons*（1990）；马克思《资本论》第一卷。以上是概念阅读线索，本文图表和案例均为原创教学内容，并非对著作的逐字引用。
