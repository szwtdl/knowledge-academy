# 第四课：工资与议价——为什么不同人的劳动报酬存在巨大差异？

> 财富与经济基础 · 第 04 课 · 2026-11-28 · 建议学习时间 30 分钟
>
> 本课案例、金额和模型参数均为教学假设，并非真实薪资统计或招聘报价。四幅图为原创教学图表。金额除特别说明外均为人民币，不讨论具体地区的劳动法律义务。

上一课讨论了产权、控制权与收益权。今天换一个角度：一个程序员为企业带来每月数万元的收入，为什么他得到的工资并不等于这些收入？两个技术水平类似的人，为什么可能获得不同薪酬？企业提高工资一定会降低利润吗？

## 学习目标（2分钟）

学完后能够区分劳动报酬、总用工成本、劳动创造的增量收益和议价结果；用外部机会计算谈判区间；解释市场竞争、搜寻成本与组织制度如何影响工资；设计兼顾经营、员工权益与长期合作的薪酬制度。

学习路线：概念（5分钟）→ 谈判案例（6分钟）→ 经营核算（6分钟）→ 市场与制度（6分钟）→ 考核（5分钟）。

## 1. 工资不是一个人的全部价值（5分钟）

工资是雇佣关系下劳动报酬的一部分。分析时需要分别看员工实际获得的薪酬、雇主承担的总成本、劳动带来的边际产出及双方的外部选择。人的尊严、照护责任与社会贡献不能直接用工资衡量。

在理想竞争模型中，企业在新增劳动的边际收益不低于边际用工成本时愿意增加用工；在完全竞争等特定假设下，最优边际条件可简化为二者相等。现实中的团队生产、资本设备、技术平台、客户关系和组织流程共同创造产出，很难将全部收入精确归到单个员工。工资还受技能稀缺性、劳动需求、求职信息、地理限制、谈判机制、法律制度与歧视等因素影响。

![工资形成的四类因素](/images/wage-04-factors.svg)

| 分析维度 | 企业要问什么 | 员工要问什么 |
| --- | --- | --- |
| 生产能力 | 此岗位对新增收益有多大贡献？ | 能解决哪些具有商业价值的问题？ |
| 外部机会 | 找到合适替代者需要多久？ | 有哪些真实可行的工作选择？ |
| 信息与风险 | 技能、产出、留任能否被验证？ | 工资、稳定性、工作时间与福利怎样？ |
| 制度与规则 | 如何定级、监督并合法支付报酬？ | 如何协商、申诉并保护自身权益？ |

工资的形成并不只取决于努力，也不只取决于谈判技巧。要把提高生产能力和改善市场选择同时纳入分析。

## 2. 案例一：技术负责人如何形成合理的谈判区间？（6分钟）

假设一家软件公司招聘技术负责人。候选人有一份等工时、等福利的替代工作，月薪2万元，因此其最低接受工资为2万元。公司预计新聘该负责人后，月度经营收益相对于不聘用该候选人的最佳替代方案增加4.2万元（已扣除其他增量经营成本，未扣除该人的工资及工资外成本）。工资外成本简化为固定的0.6万元/月。公司最高愿付工资为3.6万元。

双方的可行工资区间是2万至3.6万元，潜在共同增益1.6万元。用一个简化的分成模型，设员工获得共同增益的比例为 b，工资等于 2 + 1.6b（万元）。这是教学模型，不是实际薪酬预测公式。

| 员工议价份额 | 工资 | 员工相对外部机会增益 | 企业相对替代方案增益 |
| --- | ---: | ---: | ---: |
| 25% | 2.4万 | 0.4万 | 1.2万 |
| 50% | 2.8万 | 0.8万 | 0.8万 |
| 75% | 3.2万 | 1.2万 | 0.4万 |

![工资谈判的可行区间](/images/wage-04-bargaining.svg)

如果候选人获得另一个条件相同、月薪2.8万元的可靠录用机会，在其他条件不变时，共同增益缩小至0.8万元，均分模型下工资变为3.2万元。若其最低接受工资升至3.8万元，则超过企业最高愿付工资，原条件下不存在双方都愿接受的合同，需要改变岗位范围、成本结构或福利条件，或者不达成交易。

**关键推论：** 能力提升可能增加企业最高愿付工资；可行外部机会改善则可能提高员工最低接受工资。两者的作用不同。证书、技术栈或跳槽次数本身不是工资保证，关键是能否转化成可验证的生产能力与真实选择。

现实还要比较奖金兑现概率、通勤、股权风险、工作时长、职业成长、福利和失业风险。不能拿一份高风险短期报价直接替代稳定工作的全口径收入。

## 3. 案例二：提高工资为什么有时反而有利于企业？（6分钟）

假设一家财税 SaaS 企业管理实施团队，比较两种月度用工方案。两种方案均有10人，业务需求足够，不考虑税费和固定成本变化。用工成本包括工资和雇主承担的相关费用；每人的业务贡献指已扣除直接业务成本、未扣除团队用工和返工离职损失的边际经营收益。

| 项目 | 方案 A：基础薪酬 | 方案 B：提高薪酬并改善培训 |
| --- | ---: | ---: |
| 每人用工成本 | 1.2万 | 1.5万 |
| 每人业务贡献 | 2.5万 | 3.1万 |
| 团队业务贡献 | 25万 | 31万 |
| 团队用工成本 | 12万 | 15万 |
| 返工、离职等额外损失 | 4万 | 2万 |
| 额外培训成本 | 0 | 1万 |
| 团队净贡献 | 9万 | 13万 |

![两种团队薪酬方案的净贡献构成](/images/wage-04-team.svg)

方案 B 净贡献增加4万元，但原因是模型假设下生产率、返工和留任发生变化，并非工资上涨本身必然创造利润。若业务贡献仍为25万元、额外损失仍为4万元，则方案 B 的净贡献只有25−15−4−1＝5万元，比 A 少4万元。

若方案 B 的额外损失确实降至2万元，则其团队净贡献为 10x−15−2−1，其中 x 是每人月业务贡献（万元）。要达到 A 的9万元，需要 x 至少为2.7万元，比原2.5万元高8%。超过此门槛才增加净贡献。

这与效率工资理论讨论的机制有关：更好的报酬可能改善留任、人员筛选和努力程度。但培训、工具、管理能力、需求不足也会影响结果。高薪并不保证高产出，低薪也不必然意味着低效率。

**经营实验：** 先选可比较的岗位小规模试点，按同一口径记录有效交付、错误率、返工工时、离职、客户满意度和总用工成本。至少控制业务难度、人员经验与季节波动，不把短期同时发生的变化直接解释为因果关系。避免以无偿加班、降低质量或侵害劳动权益换取指标改善。

## 4. 案例三：为什么招聘信息和流动成本也会影响工资？（3分钟）

假设三个雇主提供同质岗位，员工的最低接受工资为6000元。若求职者能轻易接触所有雇主，且雇主竞争充分，报价可能更接近岗位创造的边际收益。若每名员工因为通勤、家庭照护、资格限制或搜寻成本，难以转向其他雇主，即使存在多家公司，单个雇主也可能拥有一定工资制定能力。

下面用一个单一雇主面对向上倾斜劳动供给的简化模型说明买方市场力量。假定所有在岗员工获得同一月薪，每位员工的新增经营收益恒为1万元，没有其他新增成本。招聘第1、2、3、4人时，为吸引足够的人员分别需将全员工资定为5000、6000、7000、8000元。

| 人数 | 全员月薪 | 工资总额 | 新增一人的边际用工成本 | 企业简化净收益 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 5000 | 5000 | 5000 | 5000 |
| 2 | 6000 | 12000 | 7000 | 8000 |
| 3 | 7000 | 21000 | 9000 | 9000 |
| 4 | 8000 | 32000 | 11000 | 8000 |

![雇主面对向上倾斜劳动供给时的成本与收益](/images/wage-04-market.svg)

在这个离散模型中，企业选择3人和7000元工资以最大化净收益。增加第4人要求同时给原员工加薪，边际成本11000元超过新增收益10000元。若引入8000元的工资下限，并假定仍有4人愿在该工资工作，则招聘4人时利润8000元，高于新条件下招聘3人的6000元；招聘人数在该模型中可以增加。

**反例与边界：** 这不是最低工资在任何情况下都会增加就业的结论。如果最低工资超过岗位的边际收益，在本模型中企业就不会招聘；竞争市场、需求弹性、不同技能岗位、价格调整和执行成本也会改变实际影响。具体政策评估需要真实数据和反事实比较。不得将模型参数当成任何国家的政策建议或法律标准。

## 5. 案例四：从个人议价到集体与组织制度（3分钟）

假设一家企业有20名同类岗位员工。各自谈判时难以获取完整薪酬信息，管理方重复协商成本也较高。企业建立透明的职级工资带、定期协商和申诉机制，可以降低信息不对称，并使薪酬与职责匹配。集体谈判也可能改善员工的共同议价能力，但需要处理岗位差异、代表性、企业承受能力与新入职者权益；具体形式取决于适用制度和法律。

不同经济理论关注不同问题：主流劳动经济学研究劳动供需、边际生产率、人力资本、搜寻摩擦和买方市场力量；制度经济学关注合同、治理和执行成本；马克思主义政治经济学区分劳动与劳动力，关注劳动力价值、工资形式以及剩余价值在资本主义生产关系中的形成。市场工资、边际产出与剩余价值不是可以直接互换的概念。企业收入减去工资也不等于马克思理论意义上的剩余价值。下一课会专门比较利润和剩余价值的分析口径。

### 企业与社会迁移

**企业制度设计：** 将岗位价值、职级能力、固定工资与浮动绩效分开。岗位评级使用可解释的职责标准；奖金基于可归因、可复核且不损害质量的指标；提供明确支付规则与申诉渠道。评估调薪时同时观察业务贡献、总成本、离职、质量和内部公平，而不是只观察工资支出。

**个人职业经营：** 选择能形成可迁移能力的项目，将技术成果整理成可核验的业务结果（如交付周期、稳定性、成本改善）；通过真实招聘反馈了解可行外部机会。保护商业秘密，不以虚假报价提高议价。

**社会制度分析：** 比较竞争政策、职业培训、公共就业信息、社会保障、劳动保护和集体协商等机制如何改变外部机会、交易成本与风险分配。评价就业数量时，也应观察工作时长、实际收入、生产率、财政成本和弱势群体的可及性。

## 6. 课后考核（5分钟）

先独立完成，再展开解析。本网站不记录个人成绩。

**第1题｜概念：** 两位程序员技术水平相同、职责相似，但一个有多个真实录用选择，另一个因为家庭照护无法远距离通勤。为什么薪资可能不同？这是否足以认定差异合理？

<details>
<summary>参考解析</summary>

不同的外部选择、通勤成本、求职摩擦和信息可能影响最低接受工资与议价结果。解释机制不等于认可结果；还需判断职责、产出、待遇规则、歧视风险及适用劳动保护。公平性与市场形成原因应分别评价。

</details>

**第2题｜数字推演：** 员工最低接受工资为1.8万元，企业月增量经营收益为3.5万元（未扣工资和固定工资外成本），工资外成本为0.5万元。计算最高愿付工资、共同增益和员工获得共同增益40%时的工资。若外部机会升至3.2万元，原条件下能否成交？

<details>
<summary>参考解析</summary>

最高愿付工资为3.5−0.5＝3万元；共同增益3−1.8＝1.2万元。工资为1.8＋1.2×40%＝2.28万元，员工增益0.48万元，企业增益0.72万元。若最低接受工资变成3.2万元，超过3万元上限，原条件下不存在双方都接受的工资。

</details>

**第3题｜制度设计：** 一家代理记账机构只按员工处理的企业户数发奖金，结果出现复杂客户无人接手、返工增加。设计改进方案并说明验证指标。

<details>
<summary>参考解析</summary>

以固定工资和岗位等级提供稳定基础，按复杂度加权计算有效交付量，质量审核、客户满意度、合规与返工纳入绩效；给复杂客户设置合理工作量，保留复核与申诉机制。试点对照时记录处理周期、差错率、返工成本、员工负荷、客户留存和总贡献，防止为了数量牺牲质量或造成不合理压力。

</details>

## 本课结论

工资既与生产能力相关，也由外部选择、市场力量、信息和制度共同塑造。企业不能将压低薪酬视为提高利润的唯一办法，员工也不能把工资看作个人价值的完整衡量。好的制度应当在法律和权益约束下，使生产效率、合理报酬、风险与长期合作可以被共同检验。

延伸阅读：Gary Becker, *Human Capital*（1964）；Alan Manning, *Monopsony in Motion*（2003）；George Akerlof 与 Janet Yellen 编，*Efficiency Wage Models of the Labor Market*（1986）；马克思《资本论》第一卷中劳动力买卖与工资相关章节。以上是理论阅读线索，不是对原文的引用；本课数值及图表均为原创教学假设。
